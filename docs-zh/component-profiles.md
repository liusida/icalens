# 成分画像

ICA 方向是一条坐标轴，并不自带语义标签。成分画像为研究者提供证据，帮助提出并检验
成分标签。

画像与分析结果中的 token 卡片互为补充：

- token 卡片展示成分在**当前输入**上的表现；
- 成分画像总结它在**画像语料**上的整体表现。

## 画像如何生成

拟合完成后，ICA Lens 会让具有代表性的文本或对话数据流经每个已拟合层。这个过程不会
重新拟合或改变 ICA 方向。对于每个成分，画像会记录：

- 分数为正或为负的频率；
- 分数平方能量在正负两侧的分布；
- 具有代表性的高能量 token 位置及其上下文；
- 每个写入方向经过 Logit Lens 投影后对应的词表 token。

画像保存在 ICA Lens 产物的 `component_profiles/` 目录中。画像数据集及其精确 revision
会与拟合来源分开记录。CLI 和 Python 工作流见[拟合与发布](fit-and-publish.md)。

## 阅读画像

在 token 卡片中选择一个成分，然后展开 **Component profile**。

![所选 ICA 成分的画像](assets/text-analysis-profile.png){ loading=lazy }

### 符号分布

**Energy** 条展示该成分的分数平方总量在整个画像语料上如何分布于正负两侧。较大的一侧
称为主导符号。**Positions** 表示每一侧出现的频率；它可能与能量不同，因为少数大分数
可以超过许多小分数的总量。

正负表示坐标方向，并不表示语义上的正面或负面。ICA 符号是任意的，因此应始终使用
当前所加载 Lens 自己记录的符号。定义见[分数与能量](scores-and-energy.md)。

### 高能量样例

这些样例来自所选成分在对应 token 分数能量中占比较大的语料位置。高亮 token 是被选中
的位置，浅色文本是它的上下文。

应把多个样例放在一起阅读。反复出现的词语、主题、句法角色或篇章模式可以帮助提出
暂定标签。这份列表只包含筛选出的高能量样例，不是该成分的全部激活，也不是整个数据集
上的词频表。

### Logit Lens token

这些 token 来自成分写入方向经过模型最终归一化层和反嵌入后的结果。它们提供第二类、
来自模型自身的线索，可以支持或质疑从语料样例中得到的解释。

对于中间层，这个投影跳过了所有后续 Transformer block。因此它只是诊断性关联，既不
预测模型将生成什么，也不能证明成分的含义就是某个列出的 token。

## 提出暂定标签

可以按以下顺序阅读：

1. 先看主导符号和高能量样例。
2. 寻找在不同上下文中反复出现的模式。
3. 检查 Logit Lens token 是否支持同一种解释。
4. 使用 `lens.analyze()` 在新输入上检验这个标签。

最终结果应被视为待检验的假设。画像可以显著加快标注，但其证据取决于画像语料，不能
替代在独立样例上的验证。
